# 💼 Carreiras em Tecnologia

Mini-site informativo sobre carreiras da área de tecnologia, feito com **HTML e CSS**. Tem uma página inicial com as carreiras e uma página para cada uma: **Análise de UX** e **Programação**.

  <img src="docs/inicio.jpg" alt="Página inicial com os cartões de Análise de UX e Programação" width="720">
</p>

## 📄 Páginas

- 🏠 **[Início](index.html):** cartões com um resumo de cada carreira
- 🎨 **[Análise de UX](carreiras/ux.html):** o que é experiência do usuário e o que faz o analista de UX
- 💻 **[Programação](carreiras/programacao.html):** o que é programação, o que faz o programador e onde ele pode trabalhar

  <img src="docs/ux.jpg" alt="Página de Análise de UX com ilustração e texto" width="720">

## ✨ Destaques

- 🎨 **Ilustrações próprias em SVG**, no lugar de imagens copiadas de outros sites
- 🌈 **Uma cor para cada carreira** (roxo para UX, verde para Programação) com variáveis CSS
- 📱 **Responsivo:** layout em grid que vira uma coluna no celular, sem quebras de linha forçadas com `<br>`
- 🧭 Menu e navegação entre as carreiras
- ♿ HTML semântico (`header`, `nav`, `main`, `aside`) e textos alternativos nas imagens

## 🛠️ Tecnologias

HTML · CSS (Grid, variáveis CSS, media queries) · SVG

## 📁 Estrutura

```
index.html                → página inicial
carreiras/ux.html         → Análise de UX
carreiras/programacao.html → Programação
css/style.css             → estilo compartilhado, com um tema por carreira
img/                      → ilustrações em SVG
```

## 🚀 Como executar

Baixe o repositório e abra o `index.html` no navegador.
